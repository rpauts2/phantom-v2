# Security

- Только своя лаба и письменное разрешение владельца систем.
- Секреты только через env (`CF_API_TOKEN`, `PHANTOM_*`), никогда в git.
- Plaintext креды не логируются и не хранятся в SQLite (только факты + Redis TTL).
- Дефолт bind dev-safe: `:443` превращается в `127.0.0.1:8443` без `PHANTOM_ALLOW_443`.
- Находки шлите приватно, без PoC против чужих систем.
